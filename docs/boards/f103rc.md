# Generic F103RC — support notes

High-density STM32F103RC (256K flash, 48K RAM, LQFP64): the full F103
peripheral set. This is the chip where the modeled superset really
exists — **DAC, FSMC, ADC3, SDIO, UART4/5, SPI3, TIM5** — alongside
everything the Blue Pill has. DBGMCU IDCODE `0x10016410`.

## Silicon peripherals (delta vs Blue Pill)

- **DAC** (2ch, PA4/PA5) — modeled with DAC→ADC loopback wire
- **FSMC** (NOR/NAND/PC-Card) — modeled with MBKEN/WREN gating + backing images
- **ADC3** — same driver as ADC1/2 (SVD map; the hardcoded map carries ADC1/2)
- **SDIO**, **UART4/5** (`0x40004C00`/`0x40005000`), **SPI3** (`0x40003C00`), **TIM5**
- GPIOA–D (64-pin package; GPIOE–G exist only on 100+ pin parts)

## Board wiring (emulator rig)

- LED: board `LED_BUILTIN` (minimum boards usually PC13; the generic
  Arduino header leaves it undefined, so firmware uses the macro)
- `Serial` = **USART2** — like Nucleo, the input box follows via `uartAddr`

## Demos on this chip (26 presets)

`board_rc_showcase`, `board_rc_rtc`) **plus the exclusive HD desk**
