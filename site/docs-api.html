High-level wrapper

import { STM32F1 } from 'stm32f1-emu';   // or './stm32f1.js' on the page
const mcu = await STM32F1.fromELF(firmware);  // fromBin / fromHex too
mcu.usart1.onData = (b) => process.stdout.write(String.fromCharCode(b));
mcu.gpio.pin('C', 13).on('change', (high) => console.log('LED', high));
mcu.onUsbIn = (ep, data) => {};
mcu.step(20000);                           // run + auto-drain events

Core emulator

import { createEmulator, chipInfo } from 'stm32f1-emu/emulator';
const emu = await createEmulator({
  firmware,                                // ELF / BIN / Intel HEX
  chip: 'gd32f103c8',                      // or { name, svd } for SVD maps
  ext_devices: { i2c_eeprom: [{ peripheral: 'I2C1', address: 0x50, data }] },
});
emu.run(200000000);                        // adaptive 20K/50K batches
emu.step(20000);                           // one batch + DMA + IRQ dispatch
chipInfo('gd32f103c8');                    // { flash, ram, idcode, label }

Host injection (test benches drive the firmware)

  • emu.uartRx(byte), emu.gpioSetInput(port, pin, level)
  • emu.canInjectMessage(addr, tir, tdtr, tdlr, tdhr)
  • emu.usbInjectSetup(bytes8), emu.usbInjectOut(ep, bytes) — IN completions arrive as UsbIn events
  • emu.i2cInjectStart(ch, addr, isRead), i2cInjectWrite, i2cInjectRead (-1 = stretch), i2cInjectStop
  • emu.spiInjectMiso(ch, bytes), emu.uartInjectBreak(addr)
  • emu.periphRead/Write(addr, w, v), emu.memRead32(addr), emu.pwmDuty(base, ch)
  • emu.onPeriphWrite(fn) — tap every peripheral write (decode shift registers, CS tracking)
  • emu.addJsPeripheral(base, size, read, write) — custom rp2040js-style peripherals
  • emu.drainEvents() — flat event queue (SPI/I2C/USART/EXTI/ADC/TIM/DAC/CRC/RTC/WDG/CAN/FSMC/USB)

Debugger surface

emu.memWriteBytes(addr, bytes) (probe-style raw writes), emu.takeFault() (one-shot fault observer), emu.setReg(i, v), emu.setPc(pc) — the building blocks behind stm32f1-emu/gdb.
