What is this?

The STM32 Bluepill Emulator is a full-system emulator for the STM32F103C8 "Blue Pill" microcontroller. It executes real, unmodified firmware — compiled Arduino sketches (STM32duino), libopencm3 and STM32Cube HAL programs — in your browser or in Node.js, without any hardware.

Instead of a simplified instruction-interpreter, it combines two real engines: Unicorn, the ARM Cortex-M3 CPU emulator (compiled to WebAssembly), and a Rust peripheral emulator that implements the chip's registers — GPIO, USART, SPI, I2C, TIM, ADC, DAC, DMA, CAN, RTC, CRC, NVIC, EXTI, FSMC and more — with realistic timing, interrupts and electrical behavior.

WASM / WebAssembly ARM Cortex-M3 Rust Runs in browser

Why use an STM32 emulator?

  • Test Arduino firmware without hardware — blink, UART, SPI Flash, I2C EEPROM, OLED, touchscreen, CAN and DMA sketches run in a tab.
  • CI & automated testing — run firmware headlessly with assertions (39 peripheral checks pass in ~9 s).
  • Debug with full visibility — inspect registers, memory, GPIO states, interrupts and the CPU state live.
  • Learn embedded systems — see how timers, DMA and interrupts actually interact, instruction by instruction.

What's emulated?

Fully implemented: GPIO (A–D) with electrical model (pull-ups, open-drain, slew), USART1–3, SPI1–2, I2C1–2, TIM1–14 (PWM, input capture, external ADC triggers), ADC1–2 with real conversion timing and an RC sample-and-hold analog model, DAC1–2 (DAC→ADC loopback), DMA1 (7 channels), CAN1 (mailboxes + filters + RX injection), RTC (alarm IRQ), CRC, NVIC (priority dispatch, SVC/PendSV/fault handling), SysTick, SCB, EXTI, AFIO, BKP, WWDG, IWDG, PWR, FLASH, and FSMC (NOR/NAND/PC-Card banks). Only USB is a stub.

How it works

The CPU executes in batches inside Unicorn; between batches the Rust peripheral model ticks — timers advance, ADC conversions complete, UART drains — and pending interrupts are injected back into the CPU. This batch model keeps the emulation accurate while staying fast enough for interactive use.
