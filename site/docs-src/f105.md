# STM32F105 (connectivity line) — support notes

Connectivity-line part run from the shipped `svd/STM32F105xx.svd` map
(rather than the builtin F103 map) because only it has **CAN2**
(`0x40006800`). The SVD omits the ARM core peripherals, so the emulator
auto-registers NVIC/SysTick/SCB at their fixed `0xE000Exxx` addresses —
without that fallback `millis()` and PendSV silently break.

## Silicon peripherals (delta vs Blue Pill)

- **CAN1 + CAN2** with the silicon-shared filter bank (CAN1 owns all 28,
  CAN2 borrows `[CAN2SB..28]`; no CAN2 filter registers)
- **USB OTG_FS device + host** at `0x5000xxxx` (IRQ 67, DFIFO0-3):
  **modeled** (see the USB OTG FS row in [PERIPHERALS](../PERIPHERALS.md)):
  `otg_cdc` preset (bare-metal CDC-ACM device, EP1 bulk echo) and
  `otg_host` preset (bare-metal HCD enumerating a scripted virtual
  device, bulk echo, live HCD trace). The F103 FS-device block
  (`0x40005C00`) does not exist on F105 silicon (and is not mapped
  there).
- **SPI3**, **UART4/5**, **TIM5–7** — modeled, same drivers
- **No** DAC, FSMC, SDIO, ADC3 (connectivity line lacks them)

## Demos on this chip (25 presets)

All 24 shared presets (periph39 passes 39/39 on the F105 map) **plus the
exclusive dual-CAN demo** (`can_dual`: CAN1+CAN2 loopback self-talk,
`test_can_dual.mjs` 5/5) **plus the exclusive USB host demo**
(`otg_host`: bare-metal HCD enumeration + bulk echo,
`tests/test_otg_host.mjs` 5/5). (USB-FS presets show on every chip but
only function where that peripheral is mapped — not here; use
`otg_cdc`/`otg_host` instead.)

## Verification

- periph39 firmware: **39/39** on the F105 SVD map
- `tests/test_can_dual.mjs` 5/5 (shared-bank filters proven end to end)
- `tests/test_otg_host.mjs` 5/5 (HCD ring proven through real machine
  code: exact trace 1..8, byte-exact echo, HPRT still set, HFNUM moves)

## Feature matrix (silicon vs emulator)

Silicon = STM32F105 connectivity line (256K flash, 64K RAM, LQFP64),
run from the shipped `svd/STM32F105xx.svd` map. Emulator = this
project's model on that SVD map (+ auto-registered NVIC/SysTick/SCB/DWT
core fallback). Statuses: **Full** = register-level incl. IRQs/DMA/
events; **Partial** = subset (see remark); **Gap** = reads zero/lenient,
no consumer; **Absent** = correctly unmapped (no such silicon here).
Other labels (Driver/IDCODE only, Out of scope) as marked.
Depth details: [PERIPHERALS](../PERIPHERALS.md).
